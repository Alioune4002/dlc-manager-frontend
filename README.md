# DLC Manager — Frontend

Interface React pour suivre des produits et faciliter la gestion des dates limites, pertes et rappels.

**Démo :** https://dlc-manager-frontend.vercel.app

## Fonctionnalités

- ajout et gestion de produits ;
- suivi des pertes ;
- rappels ;
- statistiques ;
- listes et formulaires de gestion.

## Stack

React et JavaScript.
